:fixture:`tmp_path` and :meth:`tmp_path_factory.mktemp() <pytest.TempPathFactory.mktemp>` no longer list the whole base temporary directory on every call to find the next free number, which made large test sessions slower with every test. Directory names are unchanged as long as only pytest writes into the base temporary directory; if something else creates or removes entries in it within one tick of the filesystem clock of a ``mktemp`` call, a different free number can be chosen, never an existing directory.
